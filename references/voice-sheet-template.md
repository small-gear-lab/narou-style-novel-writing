# ボイス早見表 + 声・呼称・沈黙演出チェック

[awesome-novel-studio](https://github.com/MJbae/awesome-novel-studio) の
`character-architect`（ボイス早見カード）と `rule-checker`（5軸ルール
チェック）を、日本語のなろう系文体向けに翻訳移植したもの。

**特にリレー小説・複数人コラボで最重要**。別人が書き継ぐ以上、単著の
小説よりもキャラの語尾・口癖がブレるリスクが遥かに高い。「前の話までは
たしかにこの人はこの喋り方だったのに、この話から急に変わった」は
リレー小説で最も起きやすい事故のひとつ。

## ボイス早見カード（キャラごとに1枚）

執筆前に、登場する主要キャラ全員分をこのフォーマットで作る（作品固有
データなので、利用側リポジトリの設定資料に置く）。

```markdown
### {キャラ名}

- 一人称: {僕/俺/私/あたし 等}
- 二人称（相手への呼び方）: {君/お前/あなた/{名前}さん 等、相手ごとに変わるなら列挙}
- 語尾・口癖: {「〜だぜ」「〜なのよ」「〜だと思うんだけど」等、特徴的な語尾や口癖}
- 台詞の平均的な長さ: {短文でポンポン話す / やや長め・理屈っぽい 等}
- 思考パターン: {すぐ結論に飛ぶ / 慎重に迷う / 茶化してごまかす 等}
- 感嘆詞・つなぎ言葉: {「マジで」「なんつーか」「えっと」等、口癖になっている合いの手}
- 絶対に言わないこと: {このキャラらしくない言い回し・態度があれば明記}
```

### 記入例（架空サンプル）

```markdown
### アズマ（ボケ役の主人公）

- 一人称: 僕
- 二人称: 相棒には愛称、初対面の年長者には基本タメ口
- 語尾・口癖: 中二病的な決め台詞（「世界はまだ、僕を知らない……」）を
  唐突に挟む。普段はテンション高めの平易な口調
- 台詞の平均的な長さ: 短め、テンポよく畳みかける
- 思考パターン: 現実逃避気味にすぐ「冒険」と言い張る。都合の悪い話は
  すぐ話をすり替える
- 感嘆詞: 効果音（「キュピーン」等）を自分の内心描写に添える（地の文演出）
- 絶対に言わないこと: 敬語・畏まった言い回し。深刻に落ち込んだままにはしない

### リン（ツッコミ役の相棒）

- 一人称: 俺
- 二人称: アズマには「お前」
- 語尾・口癖: ツッコミは基本的に言い切り・断定形（「行かない」「帰れ」）。
  疑問形のツッコミも多用（「なんでだよ」）
- 台詞の平均的な長さ: 短い。長台詞は言わない
- 思考パターン: 一度は必ず疑ってから折れる。最終的には巻き込まれる
- 絶対に言わないこと: 中二病的な言い回し、深く考えた風の長台詞
```

利用側リポジトリでは、この記入例の形式に沿って**その作品固有のキャラ**を
書く（この記入例自体を編集して使い回さない — あくまで書式の見本）。

## 5軸ルールチェック（執筆後）

`ai-smell-jp.md` の Gate A〜C（禁止表現・AI文体）と役割分担する。
こちらは**声・呼称・演出パターンの一貫性**に特化する。

### 軸1: ボイス一貫性（VOICE）

- 全キャラの台詞を、上記ボイス早見カードと1行ずつ照合する
- **ボイス融合**（別のキャラが同じ感嘆詞・口癖・語尾を使ってしまう）を
  重点的に探す。特にリレーで別作者が書く場合、前作者のキャラの口癖を
  無意識に新キャラにも使い回してしまう事故が起きやすい
- 内面独白が台詞と同じくらい長くなっていないか（そのキャラが元々
  そういうタイプでない限り、独白は短めに保つ）

### 軸2: 呼称・関係性の一貫性（TITLE）

- 「話者×相手」の呼び方マトリクスを作り、話をまたいで矛盾がないか確認
  （例: カエルクがマリオを「マリオ」と呼んでいたのに、次の話で唐突に
  「お前」に統一されて名前を呼ばなくなる、等の変化は関係性の変化として
  意図的でない限り避ける）
- **直前の話と呼称が食い違う**のは最重要度で確認する（リレー小説では
  特に、前話の呼称を確認せずに書き始めると起きやすい）

### 軸3: 沈黙・無言演出の乱用（SILENCE）

なろう系のギャグ寄り展開では「絶句」「無言」「沈黙」のようなリアクション
がテンポ作りに便利なぶん、多用しがちで単調になりやすい。

- 「絶句した」「言葉を失った」「沈黙が流れた」「何も言えなかった」
  「黙り込んだ」のような**無言演出**の出現回数を1話単位で数える
- 目安: 1話につき4回まで。5〜6回で要注意、7回以上は明確に多すぎる
- 3人以上のキャラが同じ無言演出（例: 全員「絶句した」）で反応している
  箇所があれば、リアクションの種類を分散させる（1人は茶化す、1人は
  無反応を装う、1人だけ本当に絶句する、等）

## 敵役・脇役の設計原則（character-architect より）

- 敵対者・障害役は「頭の悪い使い捨てキャラ」にしない。合理的な動機と
  相応の立場を持たせる（例: ゲアツカは単なる悪役ではなく、自分自身も
  さらに上から搾取されている構造の中間管理職として描かれている —
  これがギャグの中でも説得力を生んでいる）
- 脇役を一度に大量投入しない。1話で覚えさせるキャラは絞る
- キャラの変化は急にしない。初登場のキャラ付けを次の話でいきなり
  裏切らない（裏切るなら、それ自体をネタとして明示的に扱う）
