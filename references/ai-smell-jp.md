# AI臭チェックリスト（日本語なろう系版）

[oh-story-claudecode](https://github.com/worldwonderer/oh-story-claudecode) の
`story-deslop` スキル（中国網文向け AI臭除去、Gate A〜G構造）を、日本語の
なろう系ハイファンタジー文体に合わせて**方法論ごと翻訳移植**したもの。
中国語の禁止語彙をそのまま訳すのではなく、日本語の文章で実際に
「AIっぽい」「量産型なろう」と言われる具体パターンに置き換えている。

## 核心原則（oh-story-claudecode から継承）

1. **改味優先、改錯ではない** — AI臭は文法ミスではなく文体の癖。「直す」より
   「削る」対象として扱う
2. **最小の変更で最大の効果** — 全文書き直さない。1語で直る文を1文書き直し
   しない。固有名詞・数字・話数タイトルは極力保持する
3. **削除優先の原則** — AI臭い一文は、まず「削っても伏線・キャラの特徴・
   話の推進力・感情の受け渡しが失われないか」を判定する。失われないなら
   **潤色せず丸ごと削る**。失われるなら情報を残したまま自然な表現に直す
4. **創作意図は変えない** — 直すのは「どう言うか」だけ。「何が起きるか」
   （展開・設定・関係性）は変えない
5. **削りすぎ注意** — 全部削って電文体（「見た。驚いた。逃げた。」のような
   単文の羅列）になったら削りすぎ。自然な口語の冗長さまで削らない

## Gate A：禁止語彙・禁止句式（出現即修正、最優先）

### 最毒句式（★5、出現即修正）

| パターン | NG例 | 直し方 |
|---|---|---|
| 否定強調オチ「〜ではなく、〜だった」 | 「それは怒りではなく、絶望だった」 | Bだけを直接書く、または具体的な行動で示す |
| 心理直叙述「〜のような気がした」「なんとなく〜な感じがした」 | 「なぜか胸騒ぎがするような気がした」 | 曖昧語を削り、身体反応か行動に置き換える |
| 万能状語「〜ながら、〜」の心情タグ | 「彼は笑いながら、どこか寂しそうに言った」 | 「どこか寂しそうに」を削って地の文か動作で示す |
| 説教オチ「この瞬間、〜と悟った／気づいた」 | 「この瞬間、彼は本当の仲間の意味を悟った」 | 丸ごと削る。悟りは読者に推測させる |
| 感情名詞主語「恐怖が彼を襲った」「怒りが込み上げた」 | 「怒りが彼の中で膨れ上がった」 | 「彼は歯を食いしばった」等、身体・行動に変換 |
| 全知の先回り「彼が知らないのは〜だった」「実は〜だったのだが」 | 「彼が知らないのは、村長がすでに嘘をついていたことだった」 | 削る。伏線として仕込みたいなら台詞や小道具で示す |

### 一級禁止語彙（出現即置換）

**紋切り型の表情描写**
瞳を細めた、目を見開いた、口角を上げた、眉根を寄せた、口の端をわずかに歪めた、
目に光が宿った

**紋切り型の心理タグ**
心の中で〜と呟いた、心の中で〜と思った、〜という予感がした、〜な気配を感じた、
胸の奥が締め付けられた、心臓が跳ねた（多用時）

**紋切り型の比喩導入**
まるで〜のような、さながら〜のごとく、〜であるかのように（比喩自体がNGではなく、
テンプレ比喩の乱用がNG。「氷のような視線」「刃のような言葉」等の使い古された
比喩は特に優先的に削る）

**書面調・翻訳体**
〜することができた（単に「〜した」で足りる場面）、〜ということだった、
〜のであった、〜せざるを得なかった（多用時）

### 二級禁止語彙（高密度出現時のみ置換）

**弱化副詞**（1話あたり合計3回まで、それ以上は密度過多）
そっと、静かに、そのまま、ふと、なんとなく

**総括・締めの紋切り型**
「そして、〜」で始まる段落締め、「〜だった。それだけのことだった。」型の
余韻オチ、「〜という、それだけの話だ」型の自己言及オチ

**説明口調の接続**
なぜなら〜だからだ（地の文での理由の後出し解説）、つまり〜ということだ、
言い換えれば〜

## Gate B：句式の紋切り型解体

| 症状 | 診断 | 直し方 |
|---|---|---|
| 3文以上連続の同一構文の羅列（排比） | 「〜も、〜も、〜も」の3連続以上 | 1〜2個に削って残りは削除、または別の構文に崩す |
| 台詞タグの単調反復 | 毎回「〜と言った」「〜と呟いた」を律儀に付ける | 動作・改行のリズムだけで話者を示す回を増やす |
| 段落長が均一 | すべての段落が3〜4行で揃っている | 見せ場の直前で1文だけの段落を挟む、逆に説明部分は長めに残す等、緩急をつける |
| 心理描写が地の文で直接説明される | 「彼は緊張していた」 | 「手のひらに汗がにじんだ」のように身体・行動で示す（Show, don't tell） |

## Gate C：なろう系特有の紋切り型（このジャンル固有）

一般的なAI臭チェックに加えて、なろう系・ライトファンタジー特有の
「量産型」と言われがちなパターンも合わせてチェックする。

| パターン | 症状 | 対処 |
|---|---|---|
| 中二病演出の空振りが毎回同じオチ | 必殺技→不発→自虐、を全話同じテンポで繰り返す | オチの種類（不発／過剰発動／誤爆／的外れな成功）を話ごとに変える |
| ステータス風まとめの形骸化 | 話末のステータス表記が内容と関係ない定型文になる | その話で実際に変化した項目（所持金・関係性・伏線）だけを載せる |
| キャラの記号が説明台詞化する | 「僕は風と音の使い手で〜」と自己紹介口調で語らせる | 地の文の一言ラベルに留め、行動で属性を示す |
| ノリツッコミのテンポが単調 | ボケ→ツッコミの往復だけで6行以上続く | 3〜4往復ごとに動作・状況描写を1文挟んでリズムを崩す |

## 使い方（判定フロー）

1. 話数分の原稿を通読し、上記 Gate A〜C に該当する箇所を洗い出す
2. 各該当箇所について「**削っても伏線・キャラの特徴・話の推進力が
   失われないか**」を先に判定する
   - 失われない → 丸ごと削る（無理に別の表現に置き換えない）
   - 失われる → 情報を保持したまま、身体・行動・台詞に変換する
3. Gate A の★5パターンが1箇所でもあれば重点的に見直す
4. 通読で「同じ言い回しが2回以上出てきた」ものは、2回目以降を別の表現に
   変えるか削る（同一原稿内での自己模倣もAI臭の一種として扱う）
5. 削りすぎて単文の羅列（電文体）になっていないか、最後に通読して確認する
